# Exercise 1 - Determinant of a 2×2 Matrix

## Problem Statement

Compute
```math
\det\begin{pmatrix}3&-2\\5&4\end{pmatrix},\qquad \det\begin{pmatrix}1&7\\2&14\end{pmatrix}.
```
Which matrix is invertible? Justify your answer.

## Theoretical Background and Concepts

For a $2\times2$ matrix, the determinant is $ad-bc$. A square matrix is invertible exactly when its determinant is nonzero.

## Step-by-Step Solution

```math
\det\begin{pmatrix}3&-2\\5&4\end{pmatrix}=3(4)-(-2)(5)=22.
```

```math
\det\begin{pmatrix}1&7\\2&14\end{pmatrix}=1(14)-7(2)=0.
```

Only the first matrix is invertible.

## Verification and Consistency Checks

The rows of the second matrix are proportional, confirming its zero determinant.
