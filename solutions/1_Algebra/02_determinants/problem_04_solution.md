# Exercise 4 - Triangular Matrix

## Problem Statement

Without expanding the determinant, compute
```math
\det\begin{pmatrix}2&4&1\\0&-3&5\\0&0&7\end{pmatrix}.
```
State the rule for an arbitrary triangular matrix and explain it using this example.

## Theoretical Background and Concepts

For any triangular square matrix, the determinant is the product of its diagonal entries.

## Step-by-Step Solution

```math
\det A=2(-3)(7)=-42.
```

No full expansion is needed because all entries below the diagonal are zero.

## Verification and Consistency Checks

All three diagonal entries are nonzero, so the determinant is nonzero.
